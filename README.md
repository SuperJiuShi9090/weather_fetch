# QWEA_API - 天气查询工具

这是一款由 <u>酒石</u> 自主开发的基于和风天气API的控制台天气查询工具，
目前支持实时/逐小时/每日天气预报、实时/逐小时/每日空气质量预报和实时预警的查询。  
当然，您当然也可以直接调用API.py和GEO_API.py的函数来完成更多更高质量的项目  
~~写的比较low，轻点喷xwx~~

### 功能特性：  
实时天气预报  
逐小时天气预报  
7日天气预报  
实时空气质量预报  
实时天气预警  

### 环境要求：  
 python 3.8+  
 和风天气API（[点此免费申请API](https://dev.qweather.com)）

## 安装
安装依赖：
```
pip install httpx
pip install dotenv
```

本项目使用 [和风天气 API](https://qweather.com) 获取数据，[点此注册API](<https://id.qweather.com/%23/register>)。

版本号：<u>v1.5.0</u>

关于API的详细文档请参阅 [使用指南](https://dev.qweather.com/docs/start/)。
